Tiga cara memperbarui kegiatan

        

        

          
Paling mudah
1. Google Sheet

            
Buat Google Sheet dengan kolom: id, judul, tanggal, sampai, tempat, kategori, peran, penyelenggara, deskripsi, caption, hashtag, foto, dokumentasi. Pilih File → Bagikan → Publikasikan ke web → CSV, salin link-nya ke sheetKegiatanCsv di config.js. Setelah itu cukup tambah baris di Sheet; website memperbarui sendiri. Template tersedia di docs/template-kegiatan.csv.

          
Rapi & terkontrol
2. Edit di GitHub

            
Buka repositori di github.com, klik file data/kegiatan.js → ikon pensil, tempel hasil "Kode data/kegiatan.js" di paling atas daftar, lalu Commit changes. Foto diunggah ke folder assets/img/kegiatan/ lewat tombol Add file → Upload files. Website diperbarui otomatis dalam 1–2 menit.

          
Dibantu AI
3. Minta Claude

            
Simpan undangan, surat tugas, foto, dan laporan kegiatan ke folder Google Drive. Lalu minta Claude: "Baca dokumen terbaru di Drive kegiatan saya, buatkan caption, dan tambahkan ke website murykuswari". Claude akan membaca dokumennya, menulis caption, dan mengirim perubahan ke GitHub.
